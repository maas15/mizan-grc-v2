Both handlers call _docx_saved_reference_dispatch. For document_type
strategy, domain dt, and language ar, the binder-accepted snapshot
supplies content, nine sections, record, and owner. The claim is built
field by field from that snapshot. Client content, client doc_type risk,
and client selected_frameworks do not become the claim.

Body/map consistency runs inside evaluate_saved_docx_fidelity after the
two digests. A stale map returns body_sections_disagree. An unexpected
business key, a bad table, or a missing section returns its own code.

The artifact dictionary on both handlers receives the snapshot sections,
final markdown, the claim, and _rel32_export_user_id from the binder
owner. prepare_rel32_export_artifact_dict copies the artifact. It does
not invent an owner. The post-prepare block sets the owner again so a
copy cannot drop it. The synchronous route receives that backend. The
asynchronous route already passes its backend.

Canonical construction, when the decision is preserve or a fidelity
refusal, skips both compiler passes and the Arabic scrub, and stores the
original section strings as narratives. validate_canonical_quality still
runs. Its blockers are kept. repair_canonical_before_freeze, on preserve,
calls validate_rel3_objectives and validate_rel3_roadmap_output_quality
on a deep copy, appends a non-empty blocker, and discards the copy.
An exception becomes saved_docx_fidelity_refused:validator_exception.
A fidelity refusal is itself a blocker. rel3_export_authoritative returns
before the writer when frozen.blocking_errors is non-empty.

Fresh frozen source: the frozen artifact is built from that canonical
object. legacy_sections, canonical narratives, and the writer snapshot
are the same section strings. Render-tree nodes render those narratives.
The writer context variable is set only around build_fn and reset in
finally. export_docx, on preserve, passes the snapshot body and section
map, not render-tree markdown.

Existing frozen source: a pre-existing frozen artifact whose sections or
markdown are not block-equivalent is refused as frozen_source_differs
and is not exported. A matching frozen artifact may be exported. The
writer still uses the request snapshot. Evidence continues to use the
selected artifact's legacy sections. No evidence check is disabled.

Returned bytes, when the gate allows them, are hashed on the ExportResult.
The async test still fails unless export_return_allowed is true, the
writer ran, the task is done, and the comparison problems are empty.
That positive test is not expected to pass while section 6 remains.
The sync test checks the owner handoff and does not treat a quality
blocker as content success.
