4. Source walkthroughs

These are readings of the proposed source. None was executed.

Non-target synchronous backend. A synchronous request that is not the
saved Arabic DT path reaches app.py 83832 without a backend argument.
The wrapper builds _rel31_backend_callables. Ordinary authoritative
exports therefore keep the baseline objective and roadmap callbacks.
The saved path still places the binder owner on the artifact before that
call, and the wrapper copies it onto the REL31 backend.

Matching legacy frozen body with a different canonical rendering.
The legacy markdown and legacy sections can satisfy
saved_body_sections_consistency while canonical_sections still hold the
old parsed tables. section_to_markdown then emits a synthesized header
and the old header as a data row. The rendered signature differs from the
nine snapshot sections, so the refusal is frozen_canonical_differs.
rel31 returns that blocker before rel3_export_with_evidence on frozen_pre.
If canonical_sections is missing, the refusal is
frozen_canonical_unavailable. Domain, language, document_type, and the
numeric strategy or artifact id are checked first. There is no owner
field on FinalDocumentArtifact, so none is invented.

Header-only table and separator-width mismatch. A bordered header, a
separator of the same width, and no data rows become a table block with
an empty row list. The saved grid creates the header row instead of
returning. A separator with a different cell count returns
malformed_table from the parser, before the block is accepted. That
width check does not by itself prove a data cell changed when the data
rows already match the header.

Inner saved construction error. After _saved_draw is on, a failure inside
_docx_pro_heading, _docx_pro_paragraph, or _docx_pro_grid_table is not
swallowed. The model function does not fall through to
_build_strategy_document_model while the saved renderer is active. The
exporter turns the resulting ValueError into an ExportResult without
bytes. This is the failure boundary. It is not an observed exception from
a run.

Wrong document type in a cover table cell. The cover-metadata scan stores
role, document_table, row, column, and section, and does not store
paragraph. _inspect attaches that comparison, then formats it.
_location_text prints the table location. The async assertion reads
cover_document_type_hits from the stored comparison, so a formatter
problem does not erase the hit.

Writer-domain mismatch. The writer record includes the domain argument.
The handoff rejects any stripped value other than the canonical code dt
or the server display labels Digital Transformation and التحول الرقمي.
The route check at the async test remains a different boundary.

Second case while the first worker remains alive. The async finally joins
once on the deadline set before POST. If the thread is still alive, it
stores that lifecycle and leaves the observers installed. The sync case
raises prior_worker_unresolved before init_db and _install. It does not
open a second 120-second window and does not clear the recorded thread.

Original duplicated or weak roadmap content. The preserve branch passes
the original section dict to validate_saved_snapshot_original.
check_roadmap_coverage sees the original joined text, including a
duplicate row and a weak output cell. The repair helpers that delete
duplicates or replace weak cells are not called. The blocker
rel3_generation_contract_failed:roadmap_weak_output is accompanied by
saved_docx_original_roadmap_defect entries. The section strings assigned
back are the ones that were read.
